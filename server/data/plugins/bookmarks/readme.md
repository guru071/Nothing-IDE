# Bookmarks

Bookmark specific lines in a file and jump between them - persists
per-file across sessions.

## Commands

- **Bookmarks: Toggle Bookmark on Current Line**
- **Bookmarks: Jump to Next Bookmark** (wraps around at the end)
- **Bookmarks: Jump to Previous Bookmark** (wraps around at the start)
- **Bookmarks: Clear All Bookmarks in File**
