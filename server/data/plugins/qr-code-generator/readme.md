# QR Code Generator

Generates a scannable QR code as inline SVG markup from the selected
text (a URL, plain text, etc.) and replaces the selection with it - open
the result in a browser or the app's live preview to see it rendered.

Uses [kazuhikoarase/qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)
(MIT License) for the actual QR encoding. "QR Code" is a registered
trademark of DENSO WAVE INCORPORATED.

## Commands

- **QR Code: Generate SVG from Selection**
