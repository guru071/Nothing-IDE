# Case Converter

Adds 5 commands to the command palette to convert the current selection(s)
between naming conventions:

- **Case: Convert to camelCase**
- **Case: Convert to PascalCase**
- **Case: Convert to snake_case**
- **Case: Convert to kebab-case**
- **Case: Convert to CONSTANT_CASE**

Detects word boundaries from camelCase, PascalCase, snake_case, kebab-case,
or space-separated input, so you can convert between any of them.
